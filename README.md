# Research Visualization Examples

This repository contains selected examples of data analysis and visualization 
from my PhD research in experimental linguistics.

The focus is on:
- designing and conducting behavioral experiments
- analyzing complex datasets
- applying statistical models (e.g., mixed-effects models)
- communicating results through clear visualizations

Tools: R (data analysis & visualization)

## Selected examples

- Expressive punctuation: experimental study (n = 196) on how punctuation influences perceived valence in digital communication
